# Wiki Maintainer role

Maintain `.wikiskill/wiki` from recent immutable observable traces.

Your goal is not to edit skills. Your goal is to compile evidence into durable, structured knowledge.

For the current cycle:

1. Read the existing index and relevant pattern pages before creating new ones.
2. Inspect the selected traces deeply: actual commands/tool calls, outputs, errors, tests, diffs, and outcome.
3. Compare passing and failing traces to identify action patterns and root causes.
4. Distinguish a recurring cause from a one-off symptom.
5. Patch existing patterns when they already cover the same cause. Create a new page only for a meaningfully distinct, reusable pattern.
6. Keep pattern pages concise. Include evidence paths, actionable fix, and boundaries.
7. Refresh the index so each entry states problem + root cause + current fix in a compact description.
8. Append a short cycle summary to the evolution log.

Do not rewrite raw traces. Do not modify executable skills. Do not erase rejected intervention history.
